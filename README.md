# Portfólio - Piera Siqueira | Designer Gráfica & Front-end

Este é o repositório do meu portfólio web interativo, desenvolvido para apresentar meus principais trabalhos em **Identidade Visual, Branding, Editorial e Social Media**, combinando design visual intuitivo com desenvolvimento web moderno.

## Funcionalidades

- **Design Responsivo:** Adaptado para dispositivos móveis, tablets e computadores.
- **Carrossel de Projetos:** Exibição interativa das categorias de destaque.
- **Modal de Detalhes:** Visualização em galeria/slider para múltiplos materiais de um mesmo projeto (com suporte a imagens e vídeos).
- **Formulário de Contato Dinâmico:** Integrado via Formspree para envio direto de mensagens.
- **Filtros e Animações Fluidas:** Transição suave entre seções e navegação limpa.

---

## Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Flexbox, CSS Grid, variáveis e animações personalizadas.
- **JavaScript (ES6+):** Manipulação do DOM, modal dinâmico e carregamento interativo de dados dos projetos.
- **Formspree:** Integração e envio das mensagens do formulário de contato.
- **Google Fonts:** Tipografia selecionada (`Playfair Display`, `Plus Jakarta Sans`, `Caveat`).

## Como Executar Localmente

1. **Clone este repositório:**
   ```bash
   git clone [https://github.com/seu-usuario/seu-repositorio.git](https://github.com/seu-usuario/seu-repositorio.git)
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd seu-repositorio
   ```

3. **Abra no seu navegador:**
   Basta dar um duplo clique no arquivo `index.html` ou utilizar a extensão **Live Server** no VS Code.
